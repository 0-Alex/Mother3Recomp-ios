Mother 3 Recomp (English) - Multi-Platform v1.0.3
=================================================

What's New in v1.0.3:
- Controller Remapping & In-Game Layout Switcher:
    * Cycle controller layouts mid-game via F9, Xbox Guide, or Back+Start with
      a crisp on-screen notification toast.
    * Switch layouts instantly or configure custom binds with "Remap Controller.bat".
    * (Note: Launcher Settings -> Controls is reserved for keyboard bindings by upstream recomp-ui).
- Native 16-Bit High-Quality Audio Engine:
    * Direct native recognition for the High-Quality Sound Mixing Mod ROM.
    * Replaced self-modifying RAM mixer with native C++ HLE 16-bit mixing pipeline,
      eliminating frame drops and audio crackling on hot audio routines.
- 100% Native Linux & Steam Deck Fixes:
    * Fixed ROM verification errors on Linux by bundling recompiled sources and
      applying translation/UPS patches during the native build.
    * Added Mother3Recomp.desktop launcher for 1-click launch on SteamOS Desktop.

1. Quick Start (Windows):
   - Run "Play Mother 3.cmd" or "Mother3Recomp.exe".
   - On first launch, the game boots directly into the Launcher screen:
        * Choose your GBA BIOS (gba_bios.bin, 16 KB retail dump).
        * Choose your ROM:
            - English MOTHER 3 Fan Translation v1.3 (.gba), OR
            - English v1.3 + High-Quality Sound Mixing (.gba), OR
            - Clean Japanese ROM, then tick "ROM patch" and select mother3.ups.
   - Click "Play" and enjoy!

2. High-Quality Sound Mixing Mod:
   - Located in "mods/High-Quality Sound Mixing/".
   - Double-click "apply_hq_sound_mod.bat" to automatically patch your English v1.3
     ROM with 16-bit sound mixing and configure the game to launch it instantly!

3. Controls & Controller Remapping:
- Controller Remapping:
    * Run "Remap Controller.bat" in the game folder to switch layouts with 1 click!
    * Layout Presets:
        - [1] Xbox / PC: A = Confirm, B = Cancel/Dash, X = Dash, Y = Confirm
        - [2] Nintendo / Switch: B = Confirm, A = Cancel/Dash, Y = Dash, X = Confirm
        - [3] Modern Trigger Dash: Right Trigger (RT) dashes!
        - [4] Classic 1:1 Hardware: Direct hardware mapping
    * Changes take effect IMMEDIATELY (hot-reloaded, no restart required).
    * Custom overrides can also be edited directly in "keybinds.ini".
- Keyboard Defaults:
    * Arrows = D-Pad / Movement
    * X = A (Confirm / Talk)
    * Z = B (Cancel / Dash)
    * C = L (Quick text / Info)
    * V = R (Map)
    * Enter = Start (In-game menu)
    * Right Shift = Select (Wake sleep)
- Gamepad Defaults (Xbox / PlayStation / PC):
    * Left Stick & D-Pad = 8-Way Movement
    * A (Cross) = Confirm / Talk
    * B (Circle) = Cancel / Dash
    * X = Dash (easy thumb run!)
    * Y = Confirm / Talk
    * LB / LT = L Shoulder (Quick text)
    * RB / RT = R Shoulder (Map)
    * Start = Start
    * Back = Select
- System Hotkeys:
    * F10 = Toggle bezel borders on/off (switches between Bezel and Clean Fullscreen)
    * F11 = In-game overlay menu (replaces default Escape)
    * Esc = Instant clean exit (cleanly saves and exits)
    * F1 = Quick save state (Slot 1)
    * F2 = Quick load state (Slot 1)
    * Hold 1 (or LT) = Rewind (up to 30s)
    * Hold 2 (or RT) = Fast-forward

4. Display & Bezel Options:
- Press F10 at any time to toggle between the decorative bezel and clean fullscreen.
- In config.ini:
    * fullscreen = 1 (enables fullscreen)
    * bezel = 1 (1 = Sunset Bezel, 0 = Clean fullscreen with no borders)
    * screen = raw (color profile: raw, backlit, frontlit, or classic)
- Sleep mode wake: press L + R + Select (C + V + Right Shift or LB + RB + Back).
