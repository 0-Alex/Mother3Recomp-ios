Mother 3 Recomp (English) - Multi-Platform v1.0.2
=================================================

What's New in v1.0.2:
- Clean Fullscreen / No Borders Mode:
    * Press F10 at any time during gameplay to toggle between the 1080p
      Sunset & Party Bezel and Clean Fullscreen (No Borders) mode.
    * Set "bezel = 0" in config.ini to launch in Clean Fullscreen by default.
- Display Profile Fix:
    * Resolved black screen issue when running on "Classic" color profile
      by adding dynamic blend fallback and direct border-free viewport mode.
- Linux & Android Ports:
    * Individual packages now available for Windows, Linux, and Android!

1. Quick Start (Windows):
   - Run "Play Mother 3.cmd" or "Mother3Recomp.exe".
   - On first launch, the game boots directly into the Launcher screen:
        * Choose your GBA BIOS (gba_bios.bin, 16 KB retail dump).
        * Choose your ROM:
            - English MOTHER 3 Fan Translation v1.3 (.gba), OR
            - English v1.3 + High-Quality Sound Mixing (.gba), OR
            - Clean Japanese ROM, then tick "ROM patch" and select mother3.ups.
   - Click "Play" and enjoy!

2. High-Quality Sound Mixing Mod:
   - Located in "mods/High-Quality Sound Mixing/".
   - Double-click "apply_hq_sound_mod.bat" to automatically patch your English v1.3
     ROM with 16-bit sound mixing and configure the game to launch it instantly!

3. Controls (Defaults):
- Keyboard:
    * Arrows = D-Pad / Movement
    * X = A (Confirm / Talk)
    * Z = B (Cancel / Dash)
    * C = L (Quick text / Info)
    * V = R (Map)
    * Enter = Start (In-game menu)
    * Right Shift = Select (Wake sleep)
- Gamepad (Xbox / PlayStation / PC):
    * Left Analog Stick & D-Pad = 8-Way Movement
    * A (Cross) = Confirm / Talk
    * B (Circle) = Cancel / Run
    * X / LB = L (Quick text)
    * Y / RB = R (Map)
    * Start = Start
    * Back = Select
- System Hotkeys:
    * F10 = Toggle bezel borders on/off (switches between Bezel and Clean Fullscreen)
    * F11 = In-game overlay menu (replaces default Escape)
    * Esc = Instant clean exit (cleanly saves and exits)
    * F1 = Quick save state (Slot 1)
    * F2 = Quick load state (Slot 1)
    * Hold 1 (or LT) = Rewind (up to 30s)
    * Hold 2 (or RT) = Fast-forward

4. Display & Bezel Options:
- Press F10 at any time to toggle between the decorative bezel and clean fullscreen.
- In config.ini:
    * fullscreen = 1 (enables fullscreen)
    * bezel = 1 (1 = Sunset Bezel, 0 = Clean fullscreen with no borders)
    * screen = raw (color profile: raw, backlit, frontlit, or classic)
- Sleep mode wake: press L + R + Select (C + V + Right Shift or LB + RB + Back).
